# Qlementine icons (vendored subset)

Source: https://github.com/oclero/qlementine-icons (MIT, © 2023 Olivier Cléro)
Set: 16px, filled-silhouette style, viewBox 0 0 16 16.

Only the icons Fengrid's UI actually uses are vendored here, under the
upstream `icons/16/<category>/<name>.svg` layout so provenance stays
auditable. The fengrid-name → qlementine-path mapping lives in
`qt/qml/components/Icons.qml` (NAME_TO_PATH).
