Paste a URL to a git repository (github.com/…/repo — cloned shallow) or to an archive (.zip, .tar.gz, .tar.xz, .7z, …), or a local archive path the server can read. It is downloaded, unpacked, and imported into a new theme folder.

Guide

Browsing

Every icon from your configured scan folders appears as a card. Use the SIZE slider to scale previews — it snaps to standard icon sizes (16, 22, 24, 32, 48, 64, 96, 128, 256) and picks the sharpest available variant for each size.

Search & filter

Press / to jump to search, Esc to clear it — search matches icon names and your tags. The chips filter by source folder/theme (with counts); dropdowns narrow by CONTEXT, file TYPE, TONE (color/mono, from the generated metadata), TAGS and COLL (collections). SORT reorders the grid. On phones the sliders button in the title row collapses the whole filter panel for a full-page grid — phones start with it collapsed, and your choice is remembered.

Tags & collections

Hover or click an icon and press TAG in the details bar to add your own tags or drop the icon into a collection. Tags and filters match instantly, and everything is stored in this browser — it survives reloads and updates. Delete tags or collections from the tag button in the title row.

Export

The download button in the top-left corner of every icon preview opens a small menu — pick a format (PNG, JPEG, WebP, ICO) and a size, and the export starts immediately; the size choice is remembered. More formats & options… opens the full export dialog with PDF, GIF, TIFF, BMP and the original file. Served over the local web server, the conversions run through ImageMagick (ICO bundles 16–64 px frames). Opened as a plain file, PNG/JPEG/WebP exports are rebuilt in the browser and other formats fall back to saving the original file.

Details & copy

Hover an icon (or tap/click it on touch devices) to see its name, theme, context, every available size variant, format, and file path. Clicking a card pins the details. The corner button on each card copies the icon's name (filename without extension) to your clipboard.

Share on your network (QR)

The QR button shows a scannable code for opening this showcase on a phone or tablet. It needs the local web server running — the fengrid launcher starts one automatically (local-only), or start a shareable one manually:

cd ~/fengrid/server && python3 serve.py

If the server was started after you opened this page, tap the QR button again — it re-reads the server state each time.

Themes

The moon/sun button switches between dark and light modes. Your choice, preview size, sort order and filters are remembered between visits.

Keyboard shortcuts

  • / — focus search
  • Esc — clear search / close dialogs

Troubleshooting

  • "Address already in use" when starting the server — an older instance is still running. Restart with serve.py --kill-existing, or pkill -f 'serve.py --port 8642'.
  • Icons not loading in Firefox — the installer copies icons next to the page for exactly this reason; re-run install.sh if you moved the install folder.
  • Missing icons — re-run install.sh and use the folder scanner to add more icon locations.
  • Adding your own icons — drop files into the icons/ folder of your install (use a subfolder as the theme name), then run fengrid-refresh (or refresh-icons.sh inside the install folder) and reload. Files dropped loose in icons/ are filed under the Manual theme; .icns/.xpm files are converted to PNG when a converter is available. With --icons link installs the scanned entries are symlinks to the originals — your own drops are still real files, and uninstalling never follows the links.
  • Importing icon sets — the folder-plus button in the title row imports sets four ways: pick a local folder (uploaded through the local server), choose a .zip archive, point at a git repository or archive URL (.tar.gz, .7z, …), or browse 200+ open-source icon sets from fengrid/icon-sets with licenses shown. Everything lands in a theme folder under icons/ and is scanned for metadata automatically — reload shows it in the source chips.
  • Updates — fengrid-update --check checks for a newer release; the weekly cron job (if enabled) does this automatically.
  • Refreshing — the circular-arrows button in the title row re-scans the icons/ folder and updates the metadata through the web server (Shift-click re-identifies every icon). The fengrid launcher starts that server automatically (local-only, loopback bind) and opens the page over http://, so refresh and every export format work out of the box; fengrid --file opens the plain file instead. From the shell the same thing is fengrid-refresh; all scripts accept --update-metadata enabled|disabled|force.
