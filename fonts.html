Browsing fonts

Every font file found in your configured font folders appears as a card with a live preview rendered in that typeface. Type your own preview text in the toolbar and adjust the size slider to see it at any scale.

Selecting & exporting

Tick the checkbox on any card, or Shift-click to select a range, Ctrl-click to toggle individual fonts. When fonts are selected a bar appears at the bottom with Export CSS (generates @font-face rules for web use) and Export ZIP (packages the font files + CSS + a README).

Font details

Click a font name to open a detail modal with the typeface rendered at multiple sizes, all installed variants of the same family, a full glyph specimen, and metadata (family, style, weight, file size, path).

Scanning folders

Run bash scan-fonts.sh --add ~/.local/share/fonts to add a font folder, then bash scan-fonts.sh to scan. The scanner copies fonts into fonts/<Family>/ and generates fonts-list.txt + font-meta.js. Metadata comes from fc-scan (fontconfig).

Supported formats

TrueType (.ttf), OpenType (.otf), Web Open Font Format (.woff, .woff2), TrueType Collection (.ttc), and Embedded OpenType (.eot).

Copying & downloading

The corner buttons on each card copy the font's family name or download the font file. In the detail modal you can download any variant of the family.
