GTK4 Icon Browser

v0.0.1 github.com/nativeit/gtk4-icon-browser

Every icon
on your machine,
one page.

A single-file, dependency-free showcase for the GTK icon themes installed on your machine. Filter it, search it, resize it, copy icon names out of it — no build step, no runtime, no server required.

Download release README Quickstart
git clone https://github.com/nativeit/gtk4-icon-browser.git && bash install.sh no sudo required

What it does

  • Every installed iconGrouped by theme, size variants deduplicated, best variant chosen per preview size.
  • Size sliderSnaps to standard icon sizes — 16 through 256.
  • Search & filterBy name, theme (with counts), and context: actions, devices, status, …
  • Hover inspectorName, theme, context, every size variant, formats, full path.
  • One-click copyCorner button on every card copies the icon's name.
  • Fully localSelf-hosted fonts, no CDN, no framework. Works offline over file://.
