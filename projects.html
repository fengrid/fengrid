Guide

What a project is

A project bundles design assets — a color scheme, typefaces, an icon pack, optionally a preview snippet — into one configured package. The same asset can belong to any number of projects.

The four parameter areas

  • Colors — apply one of your saved palettes (roles are assigned automatically), then fine-tune each color role: background, surface, ink, muted text, accent, border. Set the corner radius and the CSS custom-property prefix.
  • Type — pick the body and heading families from your installed fonts; choosing a family adds every installed style of it to the project, so exports carry the complete set. A base size and modular scale ratio generate the type ramp.
  • Icons — pick icons for the pack and set their size.
  • Preview — render the live preview as the built-in boilerplate website, or pick a snippet: its HTML/CSS/JS renders inside the token environment (your colors, fonts, and icons apply).

Live preview

The right pane renders a full boilerplate site — header, hero, cards with icons, a type specimen, the palette strip, and a footer — redrawing as you tweak. Everything is driven by the design tokens you configured.

Exporting

Save project (Ctrl+S) persists the configuration; Export .zip / .tar.gz generates the template files: css/tokens.css (design tokens — color roles, radius, font stacks, type scale), css/fonts.css, css/icons.css, js/icons.js, the boilerplate index.html, the preview snippet as a ready page, palettes.json, manifest.json, and a README — a small custom frontend framework starter you can drop into any project.

Keyboard

  • Ctrl+S — save project
  • Esc — close dialogs
