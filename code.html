Guide

Editing & preview

Three tabbed editors — HTML, CSS, JS — sit beside a live Result pane. Press Run ▸ or Ctrl+Enter to render the snippet; the Result reloads whenever you save.

Saving snippets

Ctrl+S saves to a local SQLite database. The first save asks for a title, description, tags, and language (web or markdown); later saves update in place. The sidebar lists snippets with search, sorting, a language filter, and a clickable tag cloud — click one to reopen it. Export HTML downloads the current snippet as a standalone file.

Importing

The Import button reads snippets from other tools: VSCode .code-snippets / .json files (comments and trailing commas are fine) and massCode's db.sqlite. Languages map onto the HTML/CSS/JS fields, tags carry over, and re-importing skips what is already present. Leave the path empty to scan the editors' default locations, or upload a file.

IDE-style editing

Emacs-style commands work in every editor: Ctrl+A/Ctrl+E line home/end, Ctrl+K kill line, Ctrl+Y yank, Ctrl+D delete char, Alt+B/Alt+F word motion, Alt+D kill word, Ctrl+X Ctrl+S save.

The VIM toggle (or Ctrl+Alt+V) enables modal editing: motions h j k l w b e 0 $ gg G, operators d c y with motions (dd yy cc dw x D C), p P paste, u undo, v visual selection, and :w to save. The current mode shows in the pane label.

Keyboard shortcuts

  • Ctrl+S — save snippet
  • Ctrl+Enter — run preview
  • Esc — close dialogs / leave vim insert mode
  • Tab — indent two spaces
